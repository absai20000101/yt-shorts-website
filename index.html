YT Shorts Automation

A personal video management and publishing automation application.

About the Application

YT Shorts Automation helps its owner manage educational and entertainment videos for YouTube.

How It Works

  • Identifies prepared videos in Google Drive.
  • Uploads videos to the owner's YouTube channel.
  • Sets uploaded videos to private for manual review.
  • Organises successfully uploaded files.
  • Maintains upload records to prevent duplicate uploads.

Google API Usage

The application uses the Google Drive API and YouTube Data API to perform authorised operations on behalf of its owner.

The application is intended for personal use and is not offered as a public service.
